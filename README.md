# HealthTrack-AI

A personal wellness analytics dashboard for tracking daily activity, hydration, sleep, and exercise.

## Features
- **Daily Wellness Logging:** Record daily metrics for activity, hydration, sleep, and exercise.
- **Interactive Trend Charts:** Switch between wellness metrics to visualize progress over time.
- **History & Insights:** Review past entries with automated daily insights.
- **Data Management:** Export logged wellness data or clear history directly from the dashboard.

## Tech Stack
- **HTML5** (`index.html`)
- **CSS3** (`styles.css`)
- **JavaScript** (`script.js`)
